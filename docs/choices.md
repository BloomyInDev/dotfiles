# Configuration choices

Why each config is the way it is. The obvious settings are left out, so this
only covers decisions that would be hard to reconstruct from reading the
files.

## Theming

**Catppuccin Frappé, Lavender accent**, wherever a program can be told to use
it: `hyprtoolkit.conf` for Hyprland's own dialogs, `qt6ct` for Qt apps
(`colors/catppuccin-frappe-lavender.conf`), and Zed (Frappé dark, Mocha
light, matching icon theme).

`waybar` carries the palette at the top of its stylesheet: pills are
`surface0`, the active workspace is Lavender, and text is white rather than
Frappé's `text` because white stays legible on a translucent bar. `rofi` is
still on its own purple, and GTK apps are on `Adwaita-dark`.

Cursor is `Bibata-Modern-Classic` at size 24, set once in `vars.cursor` and
applied at session start.

## hypr

**Lua, not hyprlang.** Hyprland deprecated the `.conf` format and warns
about it at every start, so Lua is the supported way to write this config.
It also allows real variables, functions and `require()`. `hyprland.lua` is
a list of requires and nothing else; every setting lives in `conf/*.lua`.

**`conf/vars.lua` is a shared table.** Each `require()` gets its own Lua
scope, so anything used in more than one file (the `SUPER` modifier, the
terminal, the launcher, the lock command) is defined once there and pulled
in with `local v = require("conf.vars")`.

**Monitors are matched by description, not by connector.** `DP-1` changes
depending on which port you plug into; the description does not. Every
location (parents' desks, home double-screen, IUT, work) is declared at
once and the rules for absent monitors are simply ignored, so plugging in
anywhere just works, with a catch-all `auto-right` rule at the end for
anything unknown.

**Display toggles live in `vars.displays`.** They never gate whether a
location works; they only pick a *different* config for a screen you already
own (lower resolution for gaming, rotation, disabling the internal panel).
The laptop spec is built by mutating one table rather than by adding more
`hl.monitor()` calls, because when two calls target the same output the last
one wins, and mutation lets several flags compose on one screen.

**Window rules go through a local `rule()` wrapper.** The shipped stubs type
`hl.window_rule()`'s argument as `HL.WindowRuleSpec`, which only declares
`name`, `match` and `enabled`, while every actual effect (`float`, `move`,
`size`, `pin`) is missing. The wrapper is typed as a plain table, which
keeps the language server quiet without disabling diagnostics globally. It
can go once the stubs cover the full spec.

**`.luarc.json` at the repo root** points lua-language-server at
`/usr/share/hypr/stubs`, which ships the typed `hl` global (autogenerated by
Hyprland). It also adds `hypr/.config/hypr/` to `runtime.path` so
`require("conf.monitor")` resolves when the editor is opened at the repo
root rather than inside `~/.config/hypr`.

**hyprlock** authenticates with a fingerprint as well as a password, and the
`$FPRINTPROMPT` variable in `placeholder_text` is what shows the reader
prompt inside the input box. It needs `fprintd` set up and a working PAM
stack; without one, the password field still works on its own.

**hypridle** runs three staged listeners: dim the backlight to 10 after
2.5 min (`brightnessctl -s` saves the level first, so `-r` restores whatever
it was), lock at 5 min, suspend at 30 min. `lock_cmd` is guarded with
`pidof hyprlock ||` so a second instance can never stack on top of the
first, and `after_sleep_cmd` forces DPMS back on so waking does not need two
keypresses.

**hyprpaper** paths point at files this repo does not ship. Source your own
wallpapers and update the paths, or hyprpaper starts with nothing to show.

**hyprlauncher** takes focus on open and caches its index between runs.

**hyprtoolkit** carries the Catppuccin Frappé palette (see Theming above),
which is what keeps Hyprland's own dialogs matching the rest of the desktop.

Keybinds are documented separately in [keybinds.md](keybinds.md).

## waybar

**Two bars, one per output class.** `config.jsonc` is an array: the full
module set on `eDP-1`, a trimmed one on `["!eDP-1", "*"]` for smaller
external screens. The `"*"` is not optional: with the negation alone,
waybar silently spawns no bar at all.

At 1366px the full set overflows and GTK silently ellipsizes a module to
`…`, so the small bar drops the date from the clock. It is still reachable:
hover for the tooltip, click to toggle the inline format.

**The font stack names `Font Awesome 7 Free` and `Font Awesome 7 Brands`
exactly.** Icon glyphs sit in the Unicode private use area, so if the family
name does not match an installed font, fontconfig picks an arbitrary
fallback and the icons render as unrelated letters rather than as missing
glyphs. Check a new glyph with `fc-list ":charset=<codepoint>" family`
before using it.

**cpu and memory live in a `group/hardware`.** The group is what carries the
pill background, so the two of them read as one module.

**Sizing is one set of tokens**, applied to every module: padding
`2px 10px`, radius `15px`, font `16px`, margin `8px 5px 8px 0`. The power
button is the exception, since it needs an explicit square `min-width`/
`min-height`, because `border-radius: 50%` on an auto-width label produces
an ellipse, not a circle. Change the padding and that square has to be
re-measured.

**`modules.jsonc`, not `.json`.** The file uses `//` comments. Waybar
strips them whatever the extension is, but editors flag them as invalid
JSON unless the name says otherwise.

## wlogout

**Reboot to Windows** calls
`systemctl reboot --boot-loader-entry=auto-windows`. The id comes from
systemd-boot's autogenerated Windows Boot Manager entry, so check it with
`bootctl list` on a new machine. No password prompt: polkit allows
`set-reboot-to-boot-loader-entry` for active local sessions.

**Button order compensates for the grid fill.** wlogout fills its grid
column-major, so the order in `layout` is not the order on screen. The
source order is arranged so the rendered result reads:

```
Lock (l)    Sleep (u)     Exit (e)
Reboot (r)  Windows (w)   Shutdown (s)
```

Session-preserving actions on top, session-ending ones below.

## env

A single file, `~/.config/environment.d/ssh.conf`, setting `SSH_AUTH_SOCK`
for the systemd user session so every graphical app finds the same agent.
It is its own package because it is not tied to any one program.

## git

**No global identity.** `useConfigOnly = true` means a commit fails with
`no name was given` unless a remote matches, which is the point. It makes
committing with the wrong address impossible rather than merely unlikely.

**One identity per forge**, selected by
`includeIf "hasconfig:remote.*.url:..."`, each with its own SSH signing key.
Adding a forge needs *two* `includeIf` blocks: git matches the remote URL
literally, and `ssh://git@host/` and `git@host:` do not match the same
pattern.

The university identity is gitignored, the rest are public addresses
anyway. Copy `example.gitconfig.example` for any forge missing one.

## kitty

Fira Code with ligatures left on, `background_opacity 0.8` to match the rest
of the desktop, audio bell off. `theme.conf` include is commented out,
colors are set inline instead.

## rofi

`drun,run` only, icons disabled: a keyboard launcher, not a grid of icons.
Fira Sans 11 to match waybar.

## zed

VSCode keymap, Catppuccin (Frappé dark / Mocha light).
`on_last_window_closed: quit_app`, so closing the last window quits
instead of leaving a headless process around.

`ssh_connections` is kept out of this file. It names internal hosts, and Zed
rewrites its own settings, so a remote added through the UI lands straight
in a tracked file.
